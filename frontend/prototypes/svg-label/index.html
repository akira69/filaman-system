What this proves—and what it does not

No V3 format. No server Chromium. Saved presets stay unchanged; legacy exports pass through the existing V1 migration. Supports bundled fonts/weights, mixed styled text, umlauts, wrap/fit, swatches, borders, aligned logos, raster images, drawing elements and normal/thermal QR. Space Mono maps 500→400 and 600→700. Color mode shows RGBA; thermal mode shows actual mono1. Browser line balancing and exact synthesized-italic/center-decoration parity remain approximations. Overflow is rejected, not silently clipped. No production integration or physical-print verification.
